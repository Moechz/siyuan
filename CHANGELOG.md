# Changelog

All notable user-visible changes to the SiYuan TOS application package.

## 3.8.9-1 — 2026-11-10

### Added
- First release. SiYuan (`b3log/siyuan:v3.8.9`, Docker Hub official image, unmodified)
  packaged as a TOS 7 Docker application, published on port 8038 and running
  as a non-root user (1000:1000).
- Persistent data is kept under `/Volume1/DockerAppData/siyuandocker/`.
